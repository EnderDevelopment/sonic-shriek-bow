# SonicShriekBow

SonicShriekBow is a Minecraft plugin that adds a custom bow with enhanced enchantments, including Power 8, Unbreaking 25, Infinity, and Flame. This bow is designed to provide a unique and powerful combat experience in Minecraft.

## Install

1. Download the plugin JAR file from the releases section of this repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Once the plugin is installed, players can obtain the Sonic Shriek Bow by using the command `/sonicshriekbow`.
2. The bow will be added to the player's inventory with the specified enchantments.
3. Players can then use the bow like any other bow in Minecraft.
